Read the descriptions, not the ranking

Star counts reward virality, not fit. A 5k-star FFmpeg skill that does exactly your cut is worth more than a 300k-star framework you'll never configure.

Most of these are skills, not servers

A skill is a folder of instructions Claude reads on demand. An MCP server is a live process. Skills are cheaper, safer and easier to audit — prefer them unless you need a real connection.

Check the license before you build on it

Media-generation repos especially: model weights and code often carry different terms. Self-hosting a music model is a licensing decision, not just an install.
